Qwen Cloud is a subscription platform that gives you access to multiple state-of-the-art AI models through a single Token Plan. Instead of managing separate accounts and billing for each model provider, you get one plan, one API key, and access to Qwen3.6-Plus, GLM-5, MiniMax-M2.5, and DeepSeek-V3.2—all compatible with OpenAI and Anthropic protocols. Whether you're building with Cursor, Cline, Claude Code, or any other AI coding tool, Qwen Cloud fits directly into your existing workflow.

## The Token Plan

One subscription unlocks all models. You pay a flat monthly fee and draw from a shared credit pool across every model Qwen Cloud supports—no per-model subscriptions, no surprise overages.

  <Card title="Standard" icon="circle">

  </Card>
  <Card title="Pro" icon="circle-dot">
