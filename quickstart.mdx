Getting up and running with Qwen Cloud takes less than five minutes. You'll create an account, pick a Token Plan that matches your usage, copy your API key, and point your AI coding tool at the Qwen Cloud endpoint. Everything is compatible with the OpenAI and Anthropic API protocols, so there's no new SDK to learn.

<Callout icon="pencil">
  Qwen Cloud's API is fully compatible with both the OpenAI and Anthropic protocols. If your tool already works with either standard, it works with Qwen Cloud—just update the base URL and API key.
</Callout>

<Steps>
  <Step title="Sign up for Qwen Cloud">
    Go to [home.qwencloud.com](https://home.qwencloud.com/) and create your account. You only need an email address to get started.
  </Step>
  <Step title="Choose a Token Plan">
    After signing in, select the plan that fits your workflow:

    | Plan | Price | Monthly credits |
    | --- | --- | --- |
    | Standard | \$30 / month | 25,000 credits |
    | Pro | \$100 / month | 100,000 credits |
    | Max | \$200 / month | 250,000 credits |

    All plans give you access to every model Qwen Cloud supports. See the [Token Plan overview](/token-plan/overview) for details on how credits are calculated per model.
  </Step>
  <Step title="Copy your API key">
    Once your subscription is active, open the **API Keys** section of your dashboard. Click **Create key**, give it a name, and copy the key to a safe location.

    <Warning>
      Your API key is only shown once. Store it in a password manager or secrets vault before closing the dialog.
    </Warning>
  </Step>
  <Step title="Configure your AI tool">
    Point your AI tool at the Qwen Cloud endpoint using these credentials:

    - **Base URL**: `https://api.qwencloud.com/v1`
    - **API key**: the key you copied in the previous step
    - **Model**: any supported model, for example `qwen3.6-plus`

    Most tools have a settings screen where you can enter these values directly. For tools that require OpenAI-compatible configuration, use the base URL above in place of `https://api.openai.com/v1`.

    To verify your setup, send a test request with curl:

    <CodeGroup>

    ```shellscript curl
    curl https://api.qwencloud.com/v1/chat/completions \
      --header "Authorization: Bearer $QWEN_API_KEY" \
      --header "Content-Type: application/json" \
      --data '{
        "model": "qwen3.6-plus",
        "messages": [
          {
            "role": "user",
            "content": "Say hello from Qwen Cloud."
          }
        ]
      }'
    ```

    ```python Python
    import os
    from openai import OpenAI
    
    client = OpenAI(
        api_key=os.environ["QWEN_API_KEY"],
        base_url="https://api.qwencloud.com/v1",
    )
    
    response = client.chat.completions.create(
        model="qwen3.6-plus",
        messages=[{"role": "user", "content": "Say hello from Qwen Cloud."}],
    )
    
    print(response.choices[0].message.content)
    ```

    </CodeGroup>

    A successful response confirms your API key and endpoint are working correctly.
  </Step>
  <Step title="Start coding" stepNumber={4}>
    Your AI coding tool is now connected to Qwen Cloud. Credits are deducted from your monthly pool as you use the models. You can monitor consumption at any time from the **Usage** section of your dashboard.

    <Tip>
      If you're using Qwen Code, see the [Qwen Code setup guide](/token-plan/tools/qwen-code) for tool-specific configuration steps and recommended model settings.
    </Tip>
  </Step>
  <Step iconType="solid" stepNumber={0}>
  </Step>
</Steps>
