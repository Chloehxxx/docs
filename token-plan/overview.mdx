The Token Plan is Qwen Cloud's subscription offering that unlocks access to multiple state-of-the-art AI models through a single account. Instead of managing separate billing relationships with each model provider, you subscribe once and draw from a monthly credit pool that works across all supported models. Every plan is private by default—your data is never used to train models.

## Models included

Your Token Plan gives you access to four leading AI models covering text, vision, speech, and image generation:

- **Qwen3.6-Plus** — Qwen's flagship large language model for text and reasoning tasks
- **GLM-5** — Zhipu AI's general-purpose model with strong multilingual capabilities
- **MiniMax-M2.5** — A multimodal model supporting text, vision, and speech
- **DeepSeek-V3.2** — DeepSeek's latest model optimized for coding and analytical workloads
