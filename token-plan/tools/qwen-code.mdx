Qwen Code is Alibaba's AI coding assistant, and it has built-in support for Qwen Cloud—so you don't need to configure a custom API endpoint or manage environment variables. Once you sign in with your Qwen Cloud account inside Qwen Code, your Token Plan credits are used automatically.

<Note>
  Qwen Code has native Qwen Cloud integration. You can connect your account directly from the settings panel without setting a custom base URL or API key.
</Note>

<Steps>
  <Step title="Install Qwen Code">
    Download and install Qwen Code from the [Qwen Code official page](https://qwencode.alibaba.com/). Follow the installation instructions for your operating system.
  </Step>
  <Step title="Open Qwen Code and go to Settings">
    Launch Qwen Code. Click the gear icon or open the **Settings** panel from the main menu.
  </Step>
  <Step title="Find the provider section">
    In **Settings**, scroll to the **AI Provider** or **Model Provider** section. This is where you choose which backend Qwen Code uses to serve AI responses.
  </Step>
  <Step title="Choose Qwen Cloud Coding Plan">
    Select **Qwen Cloud Coding Plan** from the list of available providers. This option uses Qwen Cloud's native integration and routes requests through your Token Plan.
  </Step>
  <Step title="Sign in with your Qwen Cloud account and confirm">
    Click **Sign in with Qwen Cloud**. A browser window opens and prompts you to log in with your Qwen Cloud credentials. After authenticating, return to Qwen Code and confirm the connection.
  </Step>
  <Step title="Save settings and start coding">
    Click **Save**. Qwen Code is now connected to your Qwen Cloud Token Plan. Open any project and start using AI features—your token usage is drawn from your plan automatically.
  </Step>
</Steps>

<Tip>
  For a full overview of what your Token Plan includes—available models, credit limits, and renewal details—see the [Token Plan overview](/token-plan/overview).
</Tip>
