---
title: "Use the OpenAI Codex CLI with Qwen Cloud AI models"
description: "Point the OpenAI Codex CLI at Qwen Cloud's OpenAI-compatible endpoint and use your Token Plan credits to run AI coding tasks from the terminal."
---

The OpenAI Codex CLI reads two environment variables—`OPENAI_API_KEY` and `OPENAI_BASE_URL`—to determine where to send requests. By setting these variables to your Qwen Cloud credentials, you redirect the Codex CLI to Qwen Cloud's OpenAI-compatible endpoint. Your Token Plan credits are used for every request.

<Steps>
  <Step title="Get your API key">
    Log in to the [Qwen Cloud dashboard](https://home.qwencloud.com/) and copy your API key from the **API Keys** section.
  </Step>
  <Step title="Set the environment variables">
    Export both variables in your terminal. Set `OPENAI_BASE_URL` to the Qwen Cloud OpenAI-compatible endpoint and `OPENAI_API_KEY` to your Qwen Cloud API key.

    <CodeGroup>

    ```bash Single session
    export OPENAI_BASE_URL="https://api.qwencloud.com/v1"
    export OPENAI_API_KEY="YOUR_QWEN_CLOUD_API_KEY"
    ```

    ```bash Persistent (add to ~/.bashrc or ~/.zshrc)
    echo 'export OPENAI_BASE_URL="https://api.qwencloud.com/v1"' >> ~/.zshrc
    echo 'export OPENAI_API_KEY="YOUR_QWEN_CLOUD_API_KEY"' >> ~/.zshrc
    source ~/.zshrc
    ```

    </CodeGroup>
  </Step>
  <Step title="Specify a model and run Codex">
    Run the Codex CLI with the `--model` flag set to a model available on your Token Plan.

    ```bash
    codex --model qwen3.6-plus "refactor this function to use async/await"
    ```
  </Step>
</Steps>

<Warning>
  Do not store your API key in shell scripts or commit it to version control. Use a secrets manager or your shell's credential store for production workflows.
</Warning>

<Note>
  The available models on your Token Plan are `qwen3.6-plus`, `glm-5`, `minimax-m2.5`, and `deepseek-v3.2`. For full plan details and credit usage, see the [Token Plan overview](/token-plan/overview).
</Note>
