---
title: "Connect Cline to Qwen Cloud for AI-assisted coding"
description: "Configure the Cline VS Code extension to use Qwen Cloud's OpenAI-compatible API, giving you access to Qwen3.6-Plus, GLM-5, MiniMax-M2.5, and DeepSeek-V3.2."
---

Cline is a VS Code extension that supports any OpenAI-compatible API provider. You can point Cline at Qwen Cloud by adding it as a custom OpenAI provider, then supplying your Qwen Cloud base URL and API key. Your Token Plan credits cover all requests made through Cline.

<Steps>
  <Step title="Get your API key">
    Log in to the [Qwen Cloud dashboard](https://home.qwencloud.com/) and copy your API key from the **API Keys** section.
  </Step>
  <Step title="Open Cline settings in VS Code">
    In VS Code, click the Cline icon in the activity bar to open the Cline panel. Click the **Settings** (gear) icon inside the panel.
  </Step>
  <Step title="Select OpenAI Compatible as the provider">
    Under **API Provider**, choose **OpenAI Compatible** from the dropdown. This unlocks the fields for a custom base URL and API key.
  </Step>
  <Step title="Enter your Qwen Cloud credentials">
    Fill in the following fields:

    - **Base URL**: `https://api.qwencloud.com/v1`
    - **API Key**: your Qwen Cloud API key
    - **Model**: the model you want to use, for example `qwen3.6-plus`
  </Step>
  <Step title="Save and start using Cline">
    Click **Save**. Cline now routes all requests through Qwen Cloud. Open a file and start a conversation to confirm the connection is working.
  </Step>
</Steps>

Here is an example of how the Cline configuration looks in your VS Code `settings.json` if you prefer to configure it manually:

<CodeGroup>

```json settings.json
{
  "cline.apiProvider": "openai-compatible",
  "cline.openAiBaseUrl": "https://api.qwencloud.com/v1",
  "cline.openAiApiKey": "YOUR_QWEN_CLOUD_API_KEY",
  "cline.openAiModelId": "qwen3.6-plus"
}
```

</CodeGroup>

<Warning>
  Keep your API key out of version control. If you commit `settings.json` to a repository, move the key to a secrets manager or use VS Code's built-in credential store.
</Warning>

<Note>
  Available models on your Token Plan are `qwen3.6-plus`, `glm-5`, `minimax-m2.5`, and `deepseek-v3.2`. For details on credit usage per model, see the [Token Plan overview](/token-plan/overview).
</Note>
