---
title: "Set up OpenCode CLI with your Qwen Cloud Token Plan"
description: "Configure OpenCode CLI to use Qwen Cloud's OpenAI-compatible API, so your Token Plan credits power every coding session in the terminal."
---

OpenCode is an open-source CLI coding agent that supports any OpenAI-compatible provider. You configure it through a `config.json` file where you define your provider details—base URL, API key, and default model. Once set up, OpenCode sends all requests to Qwen Cloud and draws from your Token Plan credits.

<Steps>
  <Step title="Get your API key">
    Log in to the [Qwen Cloud dashboard](https://home.qwencloud.com/) and copy your API key from the **API Keys** section.
  </Step>
  <Step title="Locate or create the OpenCode config file">
    OpenCode stores its configuration in `~/.config/opencode/config.json`. If the file does not exist, create it:

    ```bash
    mkdir -p ~/.config/opencode
    touch ~/.config/opencode/config.json
    ```
  </Step>
  <Step title="Add the Qwen Cloud provider">
    Open `~/.config/opencode/config.json` and add the provider configuration shown below. Replace `YOUR_QWEN_CLOUD_API_KEY` with your actual key.
  </Step>
  <Step title="Set a default model">
    In the `model` field, specify one of the models available on your Token Plan: `qwen3.6-plus`, `glm-5`, `minimax-m2.5`, or `deepseek-v3.2`.
  </Step>
  <Step title="Run OpenCode">
    Launch OpenCode from your terminal in any project directory. It reads the config file automatically and connects to Qwen Cloud.

    ```bash
    opencode
    ```
  </Step>
</Steps>

Here is a complete example configuration:

<CodeGroup>

```json ~/.config/opencode/config.json
{
  "provider": {
    "name": "qwen-cloud",
    "baseUrl": "https://api.qwencloud.com/v1",
    "apiKey": "YOUR_QWEN_CLOUD_API_KEY"
  },
  "model": "qwen3.6-plus"
}
```

</CodeGroup>

<Note>
  You can switch models by changing the `model` field in `config.json`. All four models on your Token Plan—`qwen3.6-plus`, `glm-5`, `minimax-m2.5`, and `deepseek-v3.2`—are available at the same base URL. For credit details, see the [Token Plan overview](/token-plan/overview).
</Note>
