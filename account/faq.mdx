The questions below cover the most common topics customers ask about the Qwen Cloud Token Plan. If you don't find what you're looking for here, visit [home.qwencloud.com](https://home.qwencloud.com/) to contact support.

\<Tip

<AccordionGroup>
  <Accordion title="How many Token Plan subscriptions can one account have at the same time?">
    Each account can subscribe to only one Token Plan at a time. If you want to switch plans, you need to cancel your current subscription first, then subscribe to the new tier.
  </Accordion>

  <Accordion title="How can I view token consumption details?">
    Log in to your Qwen Cloud dashboard at [home.qwencloud.com](https://home.qwencloud.com/) to view your usage history and remaining credits. The dashboard shows credits used, credits remaining, and a per-request breakdown of your API activity.
  </Accordion>

  <Accordion title="Does the Token Plan support multiple users?">
    One subscription is tied to one account. For team access, each member needs their own subscription. There is no shared-seat or team plan option at this time.
  </Accordion>

  <Accordion title="Can I get a refund for the Token Plan?">
    Refunds are not available for the Token Plan. You may cancel at any time, but no partial-month refunds are issued. Your credits and API access remain active until the end of your current billing cycle after you cancel.
  </Accordion>

  <Accordion title="Which AI models are included in the Token Plan?">
    All plans include access to the following models:

    - Qwen3.6-Plus
    - GLM-5
    - MiniMax-M2.5
    - DeepSeek-V3.2

    The model you call determines how many credits each request consumes. See the [credit details](/token-plan/credits) page for a per-model breakdown.
  </Accordion>

  <Accordion title="What tools work with Qwen Cloud?">
    Any tool that supports OpenAI or Anthropic API protocols is compatible with Qwen Cloud. See the AI Tools section of the documentation for setup guides specific to popular tools and frameworks.
  </Accordion>

  <Accordion title="What happens when I run out of credits?">
    When your monthly credits are exhausted, API calls will stop succeeding until the next billing cycle. There is no automatic overage or top-up. To restore access before your credits reset, upgrade your plan to a higher tier. See the [pricing page](/token-plan/pricing) to compare plans and upgrade.
  </Accordion>
