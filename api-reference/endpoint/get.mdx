---
title: "GET /v1/models — list available Qwen Cloud models"
description: "GET /v1/models returns the list of AI models available on your Qwen Cloud Token Plan, including model IDs, object types, and ownership metadata."
---

The `GET /v1/models` endpoint returns a list of all AI models your Token Plan gives you access to. Use this endpoint to confirm which models are available before sending a chat completion request, or to dynamically populate a model selector in your application.

## Request

**Method:** `GET`  
**URL:** `https://api.qwencloud.com/v1/models`

### Headers

<ParamField header="Authorization" type="string" required>
  Your API key as a Bearer token. Format: `Bearer YOUR_API_KEY`.
</ParamField>

This endpoint does not accept a request body.

### Example request

```bash curl
curl https://api.qwencloud.com/v1/models \
  --header "Authorization: Bearer YOUR_API_KEY"
```

## Response

The endpoint returns a JSON object with a `data` array. Each element in the array represents one available model.

### Response fields

<ResponseField name="object" type="string">
  Always `"list"` for this endpoint.
</ResponseField>

<ResponseField name="data" type="object[]">
  Array of model objects.

  <Expandable title="properties">
    <ResponseField name="id" type="string">
      The model identifier you pass in the `model` field of a chat completion request. For example, `"qwen3.6-plus"`.
    </ResponseField>

    <ResponseField name="object" type="string">
      Always `"model"`.
    </ResponseField>

    <ResponseField name="created" type="integer">
      Unix timestamp (seconds) representing when the model was registered.
    </ResponseField>

    <ResponseField name="owned_by" type="string">
      The organization that owns the model.
    </ResponseField>
  </Expandable>
</ResponseField>
